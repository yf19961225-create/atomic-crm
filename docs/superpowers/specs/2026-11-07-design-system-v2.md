# ROMIKU Design System 2.0 — 三页面试点

## 边界
用户已授权连续设计、实现与 Preview 验收。基线 a62cb914；仅工作台、订单列表、订单新建/编辑及其导航外壳启用，其他页面继续旧主题。本轮不发布 Production，不修改数据库/RPC/计算/导出/询盘 API。

## 方案选择
采用现有 Tailwind v4 + Radix/Shadcn 组件和语义 CSS Token；不增加 UI 框架。页面作用域允许后续逐页接入，避免全局选择器立即改变未验收模块。业务组件不重新实现；仅增加布局类和展示分组。

## 设计规范
- 页面 #f5f7fb，卡片 #fff，正文 #172338，次要文字 #59677b，边框 #e2e8f0。
- 交互蓝 #2455d6，浅蓝 #edf3ff；红 #b42318 用于错误，橙色用于真实警告。状态必须同时有文字，不能仅靠颜色。
- 字体：Inter Variable → Noto Sans SC → PingFang SC → Microsoft YaHei → system-ui → sans-serif。现有 Fontsource OFL 字体本地打包，无 Google Fonts 请求。Inter 维持现有；中文400/600按 unicode-range 下载，font-display:swap；不预载全部中文字库，不将字体加入 PWA 全量预缓存。
- 标题24/32px、模块18/26px、正文14/22px、按钮和表头13/20px、辅助12/18px。数字 tabular-nums，金额右对齐，SKU不改变大小写。
- 间距4/8/12/16/24/32px；卡片圆角12px，输入/按钮8px，边框1px。按钮输入桌面36px，移动触摸44px；手机输入16px防缩放。
- 表格行至少48px，表头40px，轻灰表头、行悬停，操作保持可见。长客户名换行；SKU搜索框保留宽度。密集产品表在带边框容器内横向滚动，不让页面溢出，不隐藏业务列。
- 桌面侧栏224px，低对比边界、蓝色选中；手机保留现有可访问抽屉。页面最大宽度1600px，桌面24px内边距、手机16px。
- 工作台维持65/35双栏、最多8条及现有统计。小屏单栏。卡片数字28px，操作区紧凑，危险状态保留原语义。
- 订单列表保持订单/采购方/状态/送货日期/订单日期/合计/待收款/操作顺序（另含选择列）。搜索筛选进入白色工具区，表格独立内容区。
- 订单新建保留现有先创建基础单据再编辑明细的流程；不新增自动保存。编辑头部按钮保留，基础摘要、商务条款、金额、产品项分组。原实时搜索、Enter、图片回退、拖拽和金额计算不变。
- 弹窗/抽屉统一白底、细边、圆角、清晰标题及焦点环；保留现有焦点锁、Esc、确认及权限。

## 推广规则
网站询盘/自主开发/客户/报价/PI/生产/装箱/供应商/产品库/日历/设置后续以同一作用域启用，先处理各模块表格、密集录入和弹窗的语义类。日期控件、表格外壳、工具栏、标题、数字对齐等共享规范复用；不重写业务页面。每个模块单独检查移动端、长文本和原有权限交互。

## 验收
1440/1280/390真实浏览器截图；三个页面前后对比。长中英文客户和SKU、至少20产品行、输入/日期/弹窗/搜索/Enter/焦点/排序/保存刷新重开。仅Preview合成QA。自动测试复用受影响业务回归，并增加作用域/长文本布局验证；typecheck/lint/build/PWA。字体请求数量及总传输量记录，不把总字体资产大小当页面初次下载量。
